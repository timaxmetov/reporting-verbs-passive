# Reporting Verbs in the Passive

Интерактивный учебный сайт по теме **Reporting Verbs in the Passive** (пассивные конструкции с глаголами сообщения). Уровень B1–B2. Объяснение на русском, примеры на английском.

**Живая версия:** https://timaxmetov.github.io/reporting-verbs-passive/

## Что внутри

- **Теория** — две конструкции (`It is said that…` и `Somebody is said to…`), таблица инфинитивов, список reporting verbs, типичные ошибки
- **Инфографика** — 6 схем: анатомия предложения, развилка веток, частотность глаголов, ось времени, конвейер из 5 ступеней, сводная шпаргалка
- **Многоступенчатая диаграмма** — интерактивная схема из 7 шагов от слуха до готового предложения
- **Тренажёр** — 3 режима: выбор формы (8 заданий), трансформация с проверкой ввода (6), сборка предложения из блоков (5)
- **Видео** — 5 роликов носителей на YouTube с превью
- **Упражнения** — 11 заданий с ответами и разбором
- **Озвучка** — Web Speech API, автоопределение русского и английского
- **Трекер прогресса** — 14 пунктов, сохраняется в `localStorage`

## Технически

Один файл `index.html` — ни сборки, ни зависимостей, ни внешних библиотек. Vanilla JS, mobile-first CSS, `IntersectionObserver` для анимаций появления, поддержка `prefers-reduced-motion`.

Единственные внешние запросы — превью видео с `i.ytimg.com`. Если они не загрузятся, на их место встают SVG-постеры, встроенные в файл.

## Локальный запуск

Откройте `index.html` в браузере. Больше ничего не нужно.

Озвучка работает на движке браузера: в Chrome и Edge русский и английский голоса есть из коробки, в Firefox русского голоса может не оказаться.
